# 网站标识资源

- `Slidebox-icon.png` / `Slidebox.icns`：用户选定的生成式应用图标，经用户授权本地去除棋盘格背景；主体保留，透明通道经检查为 0–255。

- `deepseek.png`：DeepSeek 官方公开 favicon，来自 https://www.deepseek.com/favicon.ico 。
- `chatgpt.png`：本机 ChatGPT.app 公开应用图标资源 `Contents/Resources/electron.icns`，用于对应网站标识。
- 两个标识均使用原图等比缩小至 64px，未重新绘制；仅在软件中识别对应服务，不表示服务方背书。
- 其余图标使用 macOS SF Symbols。交互设计参考 Slidepad（https://slidepad.app），本项目与其无关联。

第三方网站名称及标识归各自权利人所有，不包含在本项目 MIT 授权范围内。
