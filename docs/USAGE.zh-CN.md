# 使用说明

1. 打开应用，将鼠标停在显示器最右侧约 200 毫秒展开侧栏。
2. 点击 + 在小型玻璃浮层中添加网站，保留底层网页；拖动网站图标调整顺序，右击可回到设定页面、编辑或删除。
3. 拖动窗口边缘调整宽高；点击外部或实心三角形收起。在设置中开启“固定侧栏”可保持展开。
4. 磨砂窄边栏默认在窗口左侧；设置 → 工具栏位置可选择左、右、上、下。左右竖排并占用 32pt 宽度，上下横排并占用 32pt 高度；按钮仍为 28pt，两侧各留 2pt，网站图标仍为 18pt。网页在剩余区域重新排版，工具栏不覆盖网页。位置会保存，网站过多时可滚动列表。
5. 设置以浮层打开，保留当前页面；从添加切换到设置再返回，未保存的添加内容仍保留。可调整网页自动休眠开关和等待时间（默认 30 秒），或开启登录启动。点击设置按钮、按 Esc 或点击浮层外可关闭。
6. 设置 → 软件更新：默认自动检查并下载最新正式版，下载完成后点击“显示安装包”，解压并手动替换应用；也可关闭自动更新或点击“检查更新”。
7. 设置 → 缓存 → 清理缓存，可清理网页资源和网站图标缓存；完成后按钮显示“✓ 清理完成”。

应用不显示 Dock 或菜单栏图标，退出入口在设置页。

工具栏使用系统磨砂叠加浅色底，呈现低透光的云母质感；图标直接排列，没有额外胶囊外框。材质随系统深浅外观变化，开启“减少透明度”时使用实色背景。添加与设置浮层在 macOS 26 及以上使用原生标准液态玻璃，macOS 15 使用系统磨砂材质，按内容收紧高度，空间不足时可滚动。网站图标保持原样；网页自身的界面不作改动，可用空间变小时可能切换为网站的紧凑布局。

收藏网址仅在手动编辑保存时修改，网页跳转不会覆盖收藏。当前浏览地址只在本次运行中记忆，退出重开后从收藏网址进入。旧版本已经覆盖的网址需右击图标 → 编辑网站，手动改回原地址。

右击网站图标 → 回到设定页面，会切换到该网站并重新打开保存的网址；已在设定页面时也可点击重新加载。收藏和登录数据保留，但未提交的输入及页面临时状态会丢失。

## 缓存清理

清理网页的内存、磁盘资源缓存和网站图标缓存；保留收藏、设置、Cookie、Local Storage、IndexedDB 和 Service Worker 数据，不访问或删除钥匙串密码。为保留登录状态，不清除网站离线数据，也不销毁当前网页；使用中可能重新生成缓存，下次加载可能稍慢。网站自身的登录过期机制仍然有效。

## 网页休眠

启用时，隐藏网页停止加载、暂停媒体，等待设定时间后释放；期限内返回复用页面，超时后按最后网址重新加载。关闭后不主动定时释放，系统仍可能节流。

Cookie 和登录数据保留，但未提交输入、临时状态及流式回答不保证恢复。网站是否在断开连接后继续生成，由网站后端决定。

## 安装与兼容

从 Releases 下载 ZIP，解压后将 Slidebox.app 拖入“应用程序”。macOS 15+，支持 Apple Silicon 和 Intel。

当前发行包使用 ad-hoc 签名，尚未通过 Apple Developer ID 公证。如果 macOS 阻止首次打开，可在确认下载来源后，按系统提示前往“系统设置 → 隐私与安全性”允许打开。

网页使用系统 WebKit；没有应用内上传、下载、搜索或导航工具栏。依赖独立弹窗的登录流程可能受限，外部浏览器登录不会自动导入。

## 构建与检查

运行 `bash scripts/build.sh` 构建通用应用，`--debug` 构建当前架构调试版。

运行生成应用的可执行文件并传入 `--self-test`、`--layout-self-test` 或 `--web-self-test`，分别检查纯逻辑、原生布局和 WebKit 生命周期。

运行 `/opt/homebrew/Caskroom/miniconda/base/envs/py312/bin/python3 scripts/check-data.py`，使用本地网页和独立临时数据存储检查收藏、休眠恢复、资源与图标缓存清理，以及 Cookie、Local Storage、IndexedDB 保留。

## 自动更新

首次启动检查 GitHub 的 `yuan-me/slidebox` 最新正式版，以后每 24 小时检查一次；重启保留限频记录，无需频繁轮询。跳过预发布版、相同版本和旧版本。手动“检查更新”可立即检查并下载，即使自动更新开关已关闭。

下载仅接受此仓库按 `Slidebox-v版本-macos-universal.zip` 命名的发行包，验证文件大小及 GitHub 的 SHA-256 摘要后才显示为可用；失败后可手动重试。已验证的安装包会复用，只保留最新下载包。关闭自动更新会取消进行中的检查或下载。

安装包位于应用沙箱的 `Library/Application Support/Slidebox/Updates`，用“显示安装包”在 Finder 定位。退出旧版后解压替换“应用程序”中的 Slidebox；程序不会自动替换自身、重启或更改登录数据。0.1.x 需要先手动升级到 1.0.0。

发布新版本时，应同时上传通用 ZIP 至 GitHub Release 并标为最新正式版。草稿、预发布版、缺失 ZIP 或 SHA-256 元数据的发行版不会下载。`--update-network-self-test` 可验证公开 GitHub 检查、下载、摘要和复用流程，使用独立配置及临时目录。
