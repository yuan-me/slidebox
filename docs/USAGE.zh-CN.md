# 使用说明

1. 打开应用，将鼠标停在显示器最右侧约 200 毫秒展开侧栏。
2. 点击 + 添加网站；拖动网站图标调整顺序，右击可编辑或删除。
3. 拖动窗口边缘调整宽高；点击外部收起，图钉可保持展开。
4. 在设置中调整网页自动休眠开关和等待时间（默认 30 秒），或开启登录启动。
5. 设置 → 缓存 → 清理缓存，可清理网页资源和网站图标缓存；完成后按钮显示“✓ 清理完成”。

应用不显示 Dock 或菜单栏图标，退出入口在设置页。

收藏网址仅在手动编辑保存时修改，网页跳转不会覆盖收藏。当前浏览地址只在本次运行中记忆，退出重开后从收藏网址进入。旧版本已经覆盖的网址需右击图标 → 编辑网站，手动改回原地址。

## 缓存清理

清理网页的内存、磁盘资源缓存和网站图标缓存；保留收藏、设置、Cookie、Local Storage、IndexedDB 和 Service Worker 数据，不访问或删除钥匙串密码。为保留登录状态，不清除网站离线数据，也不销毁当前网页；使用中可能重新生成缓存，下次加载可能稍慢。网站自身的登录过期机制仍然有效。

## 网页休眠

启用时，隐藏网页停止加载、暂停媒体，等待设定时间后释放；期限内返回复用页面，超时后按最后网址重新加载。关闭后不主动定时释放，系统仍可能节流。

Cookie 和登录数据保留，但未提交输入、临时状态及流式回答不保证恢复。网站是否在断开连接后继续生成，由网站后端决定。

## 安装与兼容

从 Releases 下载 ZIP，解压后将 Slidebox.app 拖入“应用程序”。macOS 15+，支持 Apple Silicon 和 Intel。

当前发行包使用 ad-hoc 签名，尚未通过 Apple Developer ID 公证。如果 macOS 阻止首次打开，可在确认下载来源后，按系统提示前往“系统设置 → 隐私与安全性”允许打开。

网页使用系统 WebKit；没有应用内上传、下载、搜索或导航工具栏。依赖独立弹窗的登录流程可能受限，外部浏览器登录不会自动导入。

## 构建与检查

运行 `bash scripts/build.sh` 构建通用应用，`--debug` 构建当前架构调试版。

运行生成应用的可执行文件并传入 `--self-test`、`--layout-self-test` 或 `--web-self-test`，分别检查纯逻辑、原生布局和 WebKit 生命周期。

运行 `/opt/homebrew/Caskroom/miniconda/base/envs/py312/bin/python3 scripts/check-data.py`，使用本地网页和独立临时数据存储检查收藏、休眠恢复、资源与图标缓存清理，以及 Cookie、Local Storage、IndexedDB 保留。
