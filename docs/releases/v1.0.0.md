## Slidebox 1.0.0

- 全新玻璃浮岛工具栏：默认左侧，可放到右、上、下，直接悬浮在网页内；保留原网站图标及紧凑按钮。
- 添加、编辑与设置采用紧凑玻璃浮层；按内容调整高度，小窗口可滚动。保留全部原设置，关闭点击缩放和输入框蓝色焦点环。
- 新增自动更新：默认每 24 小时检查 GitHub 最新正式版，自动下载并校验 SHA-256；在设置中显示安装包位置，由用户解压并手动替换应用。可关闭自动检查与下载，也可随时手动检查。
- 下载和校验在界面线程之外执行；复用已校验安装包，只保留最新下载包。网站图标的网络读取和缩略图处理移出主线程，开关浮层不重建网页或工具栏。
- 保留收藏、登录数据、网页休眠、拖动排序和回到设定页面等功能。未提交的网页输入和页面临时状态仍可能在休眠释放后丢失。

### 安装

下载 `Slidebox-v1.0.0-macos-universal.zip`，解压后退出旧版，将 `Slidebox.app` 替换到“应用程序”。从 0.1.x 首次升级需手动下载安装；1.0.0 起支持自动下载后续更新。

支持 macOS 15+、Apple Silicon / Intel。macOS 26+ 使用原生玻璃，旧系统使用磨砂材质。本版本为 ad-hoc 签名，未通过 Apple Developer ID 公证；SHA-256 文件用于验证下载完整性。
