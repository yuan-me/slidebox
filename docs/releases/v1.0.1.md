## Slidebox 1.0.1

- 工具栏改为独立的 32pt 磨砂窄边栏，支持左、右、上、下四个方向，网页在剩余区域重新排版，不再被工具栏遮挡。
- 移除工具栏胶囊外框与阴影，采用低透光云母质感；按钮保持 28pt、两侧各留 2pt，网站图标保持 18pt。开启系统“减少透明度”时使用实色背景。
- 添加与设置继续使用紧凑玻璃浮层，限制在网页区域内；点击边栏空白处可关闭浮层。切换位置或调整窗口大小时保留网页实例及添加草稿。
- 保留收藏、登录数据、网页休眠、拖动排序、回到设定页面及自动检查更新功能。

### 安装与更新

1.0.0 用户可在设置 → 软件更新 → 检查更新，下载并校验 v1.0.1 后点击“显示安装包”。解压安装包，退出 Slidebox，将新的 `Slidebox.app` 替换到“应用程序”后重新打开。应用不会自动替换自身；退出前请保存网页中未提交的输入。

也可直接下载 `Slidebox-v1.0.1-macos-universal.zip`。支持 macOS 15+、Apple Silicon / Intel；版本号 1.0.1 / build 5。安装包为 ad-hoc 签名，未经 Apple Developer ID 公证；附带 SHA-256 校验文件。
